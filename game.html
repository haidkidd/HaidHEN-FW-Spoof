HaidHEN Games TEST

Catálogo de arquivos PKG para usar no próprio navegador do PS4.

Prepare o console

1. Inicie o HEN ou HaidHEN normalmente.
2. Habilite o Payload Server (BinLoader), se o seu HEN oferecer essa opção.
3. Para instalação direta, é necessário também um instalador remoto compatível com a API HTTP na porta 12800.

Importante: o Payload Server TCP da porta 9090 não instala PKGs sozinho. Esta versão não injeta um payload novo automaticamente. A página pode abrir o catálogo e tentar enviar comandos a um instalador HTTP já existente, sujeito às restrições do navegador.

Instalação remota experimental
